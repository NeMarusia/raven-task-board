# Roadmap

Raven Task Board is an early local-first open-source task board. This roadmap is intentionally small: the app should stay useful, personal and not become a tiny Jira with feathers.

## Near term

- [ ] Public demo mode for GitHub Pages without personal data.
- [ ] Cleaner onboarding: sample board + first-run tips.
- [ ] Custom areas/columns from UI.
- [ ] Safer public deployment notes for reverse proxy auth.
- [ ] More neutral demo screenshots without real work tasks.

## Desktop

- [ ] Code signing / notarization for macOS and Windows.
- [ ] Auto-update strategy.
- [ ] Clear first-run warning explaining unsigned builds.
- [ ] Better file picker/onboarding for Obsidian vaults.

## Tasks and data

- [ ] Recurring tasks.
- [ ] Tags.
- [ ] Markdown task-list import/export.
- [ ] Search improvements.
- [ ] Optional archive cleanup/export.

## Mobile / PWA

- [ ] PWA mode.
- [ ] Small-screen layout pass.
- [ ] Better touch drag/drop fallback.

## Familiar nonsense, because joy matters

- [ ] More raven reactions.
- [ ] More hats/perches that render consistently without OS-dependent emoji surprises.
- [ ] Better parrot mode assets.
- [ ] Achievement tuning so rewards feel cute, not noisy.
